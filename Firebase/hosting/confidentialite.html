Politique de confidentialité

Ce que CNSNN enregistre, pourquoi, et comment tout effacer.

Dernière mise à jour : 14 octobre 2026.

Qui est responsable

CNSNN est un jeu édité par un développeur indépendant, « Poupoutch », responsable du traitement de vos données. Pour toute question ou demande : jeucnsnn@gmail.com.

Les données enregistrées

  • Votre compte : un identifiant technique créé automatiquement (compte invité), votre pseudo et, si vous créez un compte permanent, votre adresse email et votre mot de passe (le mot de passe est géré par Firebase Authentication, nous ne le voyons jamais).
  • Vos parties : vos résultats au mot du jour (temps, points, erreurs, indice utilisé), votre série, votre historique d’entraînement et vos statistiques.
  • Vos contributions : les cartes que vous proposez, vos signalements de cartes ou de pseudos, votre acceptation des règles de la communauté.
  • Vos amis : votre code ami et la liste des joueurs que vous avez ajoutés.
  • Les rapports de plantage : si l’application plante, un rapport technique (modèle et système de l’appareil, version de l’application, endroit du code concerné) est envoyé à Firebase Crashlytics. Il ne contient ni votre pseudo, ni votre email. (Application Android uniquement.)

CNSNN n’affiche aucune publicité, n’utilise aucun traceur publicitaire ni outil de mesure d’audience, et ne vend ni ne partage vos données.

Pourquoi

  • Faire fonctionner le jeu : vous identifier, sauvegarder et synchroniser votre progression, calculer les classements (exécution du service que vous utilisez).
  • Protéger la communauté : modérer les pseudos et les cartes, lutter contre la triche, traiter les signalements (intérêt légitime).
  • Corriger les plantages (intérêt légitime).

Ce que voient les autres joueurs

Votre pseudo et vos résultats officiels du mot du jour apparaissent dans les classements. Vos amis voient votre résultat du jour. Votre email n’est jamais affiché. Les cartes que vous proposez n’affichent pas votre nom aux autres joueurs.

Où sont les données

Sur votre appareil, et sur les serveurs de Firebase (Google), qui héberge les comptes, la base de données et les rapports de plantage. Ces serveurs peuvent se trouver hors de l’Union européenne ; Google s’engage alors par les clauses contractuelles types de la Commission européenne. Le rappel du mot du jour et le widget sont calculés sur votre appareil : aucune notification n’est envoyée par un serveur.

Combien de temps

Vos données sont conservées tant que votre compte existe. Quand vous le supprimez, tout est effacé immédiatement : profil, résultats, place au classement, amis, code ami, signalements, propositions non publiées, et signalements vous concernant. Les cartes déjà publiées restent dans le jeu, sans votre nom ni votre identifiant. Seule une trace anonyme (l’identifiant technique et la date de suppression) est gardée pour retirer votre compte des listes d’amis des autres joueurs. Les rapports de plantage sont effacés par Firebase au bout de 90 jours.

Supprimer votre compte

  • Dans l’application : Profil, puis Mon compte, puis Supprimer mon compte.
  • Sur le web, sans l’application : cnsnn-9ctosy.web.app/suppression, avec l’email et le mot de passe de votre compte.
  • Pour un compte invité dont vous n’avez plus l’appareil : écrivez à jeucnsnn@gmail.com avec votre pseudo et, si possible, votre code ami.

Vos droits

Vous pouvez accéder à vos données, les corriger (votre pseudo se modifie dans le profil), les effacer, en demander une copie ou vous opposer à un traitement en écrivant à jeucnsnn@gmail.com. Si vous estimez que vos droits ne sont pas respectés, vous pouvez saisir la CNIL (cnil.fr).

Enfants

CNSNN convient à tous. Si vous avez moins de 15 ans, demandez l’accord d’un parent avant de créer un compte avec votre email.

Ce site

Ce site n’utilise aucun cookie. La page de suppression de compte se connecte à Firebase le temps de la suppression, sans rien garder dans votre navigateur.
