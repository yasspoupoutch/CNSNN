Comment jouer

  • Chaque jour, le même mot pour tous : facile en début de semaine, difficile le week-end.
  • Tapez le mot complet, les accents sont ignorés. Un indice si vous séchez, contre la moitié des points.
  • Comparez votre temps avec vos amis grâce à votre code ami, et gardez votre série.
  • Le mode Classique, sans limite, pour s’entraîner. Proposez vos propres mots à la communauté.
